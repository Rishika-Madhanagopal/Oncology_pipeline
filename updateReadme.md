# Precision Oncology: Multi-Omic Drug Sensitivity Prediction

## Overview

This project predicts breast cancer drug sensitivity by training machine learning
models on DepMap cancer cell line data (mutation, copy number, and gene expression)
and applying the trained models to real TCGA-BRCA patient tumors. The entire
feature-engineering layer is built in SQL over DuckDB rather than ad hoc pandas
scripts, and every model's predictions are interpreted using SHAP.

**Core design decision:** models are trained exclusively on DepMap cell lines
(where drug response is actually measured) and then *applied* to TCGA patients
(who were never given these drugs) — this avoids the common but flawed practice
of "borrowing" a drug label from the nearest cell line and pretending it belongs
to a patient.

## Architecture

GDC (expression) ────┘ │
│ apply trained model
DepMap (mutation, CNV, expression) ─┐ ▼
DepMap PRISM (drug response) ───────┼─→ Cell line training set (1,105 cell
│ lines, pan-cancer) → ElasticNet + CV
└─→ SHAP interpretation → predicted patient
sensitivity +
subtype sanity check


## Tools & Libraries

| Layer | Tool |
|---|---|
| Feature engineering | DuckDB (embedded OLAP SQL — `PIVOT`/`UNPIVOT`, window functions) |
| Data acquisition | GDC REST API, cBioPortal, DepMap Portal |
| Modeling | scikit-learn (`ElasticNetCV`, `SelectKBest`) |
| Interpretability | SHAP (`LinearExplainer`) |
| Pathway enrichment | R, `gprofiler2` |
| Gene coordinate reference | UCSC `refGene` (hg38) |
| Visualization | matplotlib, ggplot2 |

## Data Sources

- **TCGA-BRCA**: mutation (MAF), copy number (segment files), and expression
  (STAR-Counts) from the GDC Data Portal; PAM50 molecular subtype from cBioPortal
  (`brca_tcga_pan_can_atlas_2018`), since GDC's harmonized clinical schema lacks
  disease-specific fields like subtype.
- **DepMap**: `Model.csv`, `OmicsSomaticMutations.csv`, `OmicsCNGeneWGS.csv`,
  `OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv` (26Q1 release), and the
  PRISM Repurposing drug-response screen (`Extended_Primary_Data_Matrix.csv`,
  24Q2 release).

## Key Results

- Feature matrices: **902 TCGA patients × 54,659 features**; **1,105 pan-cancer
  DepMap cell lines × 46,614 features**.
- Of 10 candidate drugs (selected by response variance), **6 showed statistically
  significant 5-fold CV correlation** between predicted and actual sensitivity;
  the strongest was **PRLX-93936** (Pearson r=0.53, p=2×10⁻⁴⁵).
- **ELACESTRANT** (an estrogen receptor degrader used clinically in breast cancer)
  was the flagship result (r=0.36, p=8×10⁻²⁰), and its top SHAP feature
  (`CYP7B1`, a steroid-metabolism gene) is mechanistically plausible.
- **BELOTECAN**'s top SHAP gene was **SLFN11** — the most well-established
  published biomarker for sensitivity to topoisomerase inhibitors and DNA-damaging
  chemotherapy — a genuine external validation of the pipeline.
- A **subtype-only baseline sanity check** (does the model just reinvent PAM50
  subtype?) showed a clean, biologically coherent split: broadly cytotoxic drugs
  (Belotecan, Ethynylcytidine, Avitinib) were largely explained by subtype
  (R²=0.35–0.46, with Basal-like patients correctly predicted as most sensitive —
  matching known clinical chemosensitivity patterns), while targeted agents
  (Elacestrant, PRLX-93936) were not (R²=0.04–0.11), meaning those predictions
  draw on real multi-omic signal beyond subtype alone.
- Pathway enrichment on top SHAP genes surfaced a mechanistically coherent hit for
  PRLX-93936 (a VDAC inhibitor): an interferon/innate-immune signature
  (IRF-1 motif, p=1.6×10⁻⁵), consistent with mitochondrial-stress-triggered
  immune signaling.

## Known Limitations

- **No formal batch correction within DepMap.** DepMap is generated by a single
  facility on one production pipeline, unlike TCGA's multi-center collection, so
  the risk is smaller — but it was not formally tested.
- **No cell-line ↔ patient domain alignment.** Cell lines and patient tumors are
  fundamentally different sample types (no tumor microenvironment, no immune
  infiltrate, in vitro vs in vivo). Independently z-scoring each dataset does not
  correct for this. A published method built specifically for this problem
  (**Celligner**, Warren et al. 2021) was identified but not implemented.
- **Cell-type deconvolution was not performed.** scRNA-seq-informed deconvolution
  of the bulk RNA-seq signal (e.g., Bisque/CIBERSORTx-style) was scoped out to
  prioritize the core cell-line → patient prediction architecture.
- **Pan-cancer training trade-off.** Training on all cancer types' cell lines
  (rather than breast-only) substantially improved statistical power (30 → 1,105
  training samples), at the cost of predictions not always tracking
  breast-specific expectations as cleanly (see ELACESTRANT's non-canonical
  subtype pattern).

## Future Work

- Implement Celligner-style cell-line/patient expression alignment.
- Add scRNA-seq-based cell-type deconvolution as an additional feature layer.
- Validate top SHAP genes (e.g., SLFN11) against independent published cohorts.
- Extend gene-level CNV mapping to indels/structural variants beyond simple
  segment-mean thresholding.

## Running the Pipeline

```bash
# SQL feature engineering (TCGA + DepMap)
python3 -c "
import duckdb, pathlib
con = duckdb.connect('db/oncology.duckdb')
con.execute(\"SET memory_limit='4GB'\")
con.execute('SET preserve_insertion_order=false')
con.execute('SET threads=1')
for f in sorted(pathlib.Path('sql').glob('*.sql')):
    con.execute(f.read_text())
"

# Train models, interpret, apply to patients, enrich
python3 scripts/model_training.py
python3 scripts/model_interpretation.py
python3 scripts/apply_model_to_patients.py
Rscript scripts/enrichment_analysis.R
